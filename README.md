# Скрытые жемчужины — выбор ресторана вслепую

Одностраничный интерактивный прототип на HTML, CSS и Vanilla JavaScript. Откройте `index.html` в браузере — сборка и сервер не нужны.

## Возможности
- Настройка бюджета, количества гостей и района поиска.
- Карточки ресторанов с фотографиями, свайпом и выбором одного понравившегося места.
- Расчёт демонстрационной цены со скидкой 40%.
- Экран планирования встречи с проверкой даты.
- Адаптивная вёрстка и поддержка `prefers-reduced-motion`.

## Важно
Это учебный демонстрационный прототип. Реальные бронирования и платежи не выполняются; названия, адреса и цены ресторанов вымышлены. Фотографии загружаются по внешним ссылкам Unsplash, поэтому для их отображения нужен интернет.
